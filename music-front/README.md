# 音乐播放器前端

一个现代化的音乐播放器Web应用，提供完整的音乐管理、播放和搜索功能。

## 🎵 功能特性

### 核心功能
- **🎵 歌曲管理**: 浏览、搜索和管理音乐库
- **🎧 音乐播放**: 流畅的音频播放体验，支持播放控制
- **📁 文件上传**: 上传音频文件和歌词文件
- **❤️ 收藏功能**: 收藏喜欢的歌曲
- **🔍 智能搜索**: 多维度搜索（标题、艺术家、专辑、流派、语言）

### 播放器功能
- 播放/暂停控制
- 上一首/下一首切换
- 进度条控制
- 音量调节
- 播放列表管理
- 自动播放下一首

### 用户界面
- 现代化响应式设计
- 侧边栏导航
- 卡片式歌曲展示
- 实时搜索
- 加载状态提示
- 消息通知系统

## 🚀 快速开始

### 前置要求
1. 确保后端Spring Boot服务正在运行 (`http://localhost:8080`)
2. 确保MySQL数据库和MinIO服务正在运行
3. 现代浏览器（Chrome、Firefox、Safari、Edge）

### 启动应用
1. 打开 `start.html` 查看启动说明
2. 点击"启动音乐播放器"按钮
3. 或者直接访问 `index.html`

## 🎮 使用指南

### 基本操作
1. **浏览歌曲**: 在"歌曲列表"页面查看所有歌曲
2. **播放音乐**: 点击歌曲卡片上的"播放"按钮
3. **搜索歌曲**: 使用顶部搜索栏或"搜索"页面
4. **上传歌曲**: 在"上传歌曲"页面添加新音乐
5. **收藏歌曲**: 点击"收藏"按钮管理收藏列表

### 播放器控制
- **播放/暂停**: 点击播放按钮或按空格键
- **上一首/下一首**: 使用播放器控制按钮或快捷键
- **进度控制**: 拖动进度条或点击进度条跳转
- **音量调节**: 使用音量滑块调节音量

### 键盘快捷键
| 功能 | 快捷键 |
|------|--------|
| 播放/暂停 | 空格键 |
| 上一首 | Ctrl + ← |
| 下一首 | Ctrl + → |
| 搜索 | Ctrl + S |
| 上传 | Ctrl + U |
| 收藏 | Ctrl + F |

## 🌐 API接口

前端通过以下API与后端通信：

### 歌曲管理
- `GET /api/songs` - 获取所有歌曲
- `GET /api/songs/{id}` - 获取指定歌曲
- `POST /api/songs/upload` - 上传歌曲
- `PUT /api/songs/{id}` - 更新歌曲信息
- `DELETE /api/songs/{id}` - 删除歌曲

### 搜索功能
- `GET /api/songs/search` - 关键词搜索
- `GET /api/songs/search/title` - 按标题搜索
- `GET /api/songs/search/artist` - 按艺术家搜索
- `GET /api/songs/search/album` - 按专辑搜索
- `GET /api/songs/search/genre` - 按流派搜索
- `GET /api/songs/search/language` - 按语言搜索

### 播放功能
- `POST /api/songs/{id}/play` - 播放歌曲（增加播放次数）
- `GET /api/songs/{id}/stream` - 流式播放
- `GET /api/songs/{id}/download` - 下载歌曲

### 歌词管理
- `GET /api/songs/{id}/lyrics` - 获取歌词信息
- `POST /api/songs/{id}/lyrics` - 上传歌词文件
- `DELETE /api/songs/{id}/lyrics` - 删除歌词文件
- `GET /api/songs/{id}/lyrics/download` - 下载歌词文件

## 🐛 常见问题

### 连接问题
**Q: 无法连接到后端API**
A: 检查后端服务是否正在运行，确认端口8080是否可用

**Q: 跨域请求被阻止**
A: 确保使用本地服务器打开前端页面，或配置后端CORS

### 播放问题
**Q: 音频无法播放**
A: 检查音频文件格式是否支持，确认MinIO服务正常运行

**Q: 播放器控制无响应**
A: 检查浏览器是否支持HTML5 Audio API

### 上传问题
**Q: 文件上传失败**
A: 检查文件大小限制，确认文件格式支持
